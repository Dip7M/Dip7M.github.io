# Dip7M Portfolio
Modern, responsive, zero-build portfolio for GitHub Pages.

## Deploy
1. Upload the contents of this folder to `Dip7M.github.io`.
2. Commit to `main`.
3. GitHub Pages will serve `index.html`.

No Node.js, npm or build step is required.

## Customize
- Put your latest resume at `assets/resume.pdf` and update the Resume button if you add one.
- Replace the LinkedIn placeholder URL in `index.html`.
- Add project repository/demo links as you create them.
